# CONCRELAGOS — Logística e Controle Compartilhado

Protótipo funcional do fluxo de Cimento (Base de Dados, Programação e Controle de Pedidos),
em um único arquivo HTML (`index.html`). Hoje os dados ficam guardados apenas no navegador
(em memória) — a ligação com um banco de dados real (Supabase) ainda será feita.

## Como rodar

Basta abrir o arquivo `index.html` em qualquer navegador. Não precisa instalar nada.

Login de teste: usuário `admin`, senha `admin`.
